# CognoRise InfoTech – Data Science Internship Projects

This repository contains three projects completed as part of my Data Science Internship at CognoRise InfoTech.

## Projects

### 1. Customer Churn Prediction
- Analyzed customer subscription data.
- Performed Exploratory Data Analysis.
- Built machine learning classification models.
- Evaluated models using Precision, Recall, F1-score and ROC-AUC.

### 2. Credit Card Fraud Detection
- Analyzed credit card transaction data.
- Investigated class imbalance.
- Applied preprocessing and sampling techniques.
- Built classification models to detect fraudulent transactions.
- Evaluated models using Precision, Recall, F1-score and ROC-AUC.

### 3. Customer Segmentation
- Analyzed customer demographic and spending data.
- Performed Exploratory Data Analysis.
- Applied K-Means clustering.
- Used the Elbow Method and Silhouette Score to evaluate clusters.
- Visualized and profiled customer segments.
